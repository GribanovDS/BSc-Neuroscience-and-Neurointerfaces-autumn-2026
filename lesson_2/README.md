## Подготовка

В начале каждого скрипта есть основные настройки:

```python
DEVICE_TYPE = DeviceType.Noise
BIPOLAR_CHANNELS = False
TARGET_SERIAL = None
```

`DeviceType.Noise` запускает тестовый генератор Capsule и позволяет проверить программу без физического устройства.

Для работы с Neiry HeadBand замените его на:

```python
DEVICE_TYPE = DeviceType.Band
```

Если рядом находится несколько устройств, запишите серийный номер в `TARGET_SERIAL`.

## 1. График ЭЭГ

Запустите:

```bash
python lesson_2/plot_eeg.py
```

`plot_eeg.py` подписывается на ЭЭГ с помощью callback-функции:

```python
device.set_on_eeg(on_eeg)
```

В `on_eeg` поступает новый пакет отсчётов. Для каждого канала значения добавляются в отдельный `deque`. Буфер хранит последние пять секунд сигнала, поэтому график непрерывно движется слева направо и не расходует всё больше памяти.

На графике показываются обработанные значения ЭЭГ, полученные через:

```python
eeg.get_processed_value(channel_index, sample_index)
```

Количество линий определяется автоматически. Оно может изменяться в зависимости от устройства и значения `BIPOLAR_CHANNELS`

## 2. График PSD

Запустите:

```bash
python lesson_2/plot_psd.py
```

Этот скрипт сохраняет график ЭЭГ и добавляет PSD, которую рассчитывает Capsule.

PSD показывает, как мощность сигнала распределена по частотам. Для получения данных используется ещё одна подписка:

```python
device.set_on_psd(on_psd)
```

В callback-функции частоты и значения PSD считываются методами:

```python
psd.get_frequency(frequency_index)
psd.get_psd(channel_index, frequency_index)
```

Логарифмическая шкала по вертикали помогает одновременно видеть компоненты сигнала, мощность которых отличается на несколько порядков

## 3. Мощность альфа-ритма

Запустите:

```bash
python lesson_2/plot_alpha_power.py
```

Альфа-диапазон в этом занятии задан от 8 до 13 Гц:

```python
ALPHA_LOW_HZ = 8
ALPHA_HIGH_HZ = 13
```

На графике PSD этот диапазон выделен жёлтым цветом.

Чтобы получить полную мощность альфа-ритма, программа интегрирует PSD по частоте отдельно для каждого канала:

```python
np.trapezoid(spectrum[alpha_mask], frequencies[alpha_mask])
```

Затем значения всех каналов усредняются. Расчёт можно записать так:

```text
Мощность альфы = среднее по каналам от интеграла PSD в диапазоне 8–13 Гц
```

## 4. Управление прогресс-баром

Запустите:

```bash
python lesson_2/eeg_progressbar_control.py
```

Финальный скрипт добавляет прогресс-бар и сравнивает каждый новый результат расчёта с фиксированным порогом:

```python
ALPHA_THRESHOLD = 6e-12
```

Если альфа-мощность равна порогу или превышает его, прогресс увеличивается на `PROGRESS_STEP_UP`. Если мощность ниже порога, прогресс уменьшается на `PROGRESS_STEP_DOWN`

```python
if alpha_power >= ALPHA_THRESHOLD:
    progress += PROGRESS_STEP_UP
else:
    progress -= PROGRESS_STEP_DOWN
```

Значение всегда ограничивается диапазоном от 0 до 100 процентов

Порог задаётся константой в начале файла. Значение `6e-12` подходит как стартовая точка для тестового устройства `Noise`, но для физического устройства его нужно подобрать по наблюдаемому графику альфа-мощности

Сначала запустите `plot_alpha_power.py` и посмотрите, какие значения возникают в спокойном состоянии и во время выполнения выбранной команды. Затем перенесите подходящее число в `ALPHA_THRESHOLD`

## Как обновляется интерфейс

`FuncAnimation` вызывает функцию `update` через короткие интервалы. В ней выполняется `locator.update()`, после чего CapsuleSDK передаёт новые данные в `on_eeg` и `on_psd`, а линии на графиках получают обновлённые значения.

Прогресс изменяется только при поступлении нового PSD-пакета. Поэтому скорость заполнения не зависит от частоты кадров интерфейса

## На что обратить внимание

Моргание, движение головы и напряжение мышц создают сильные артефакты и могут менять PSD. Рост мощности в диапазоне 8–13 Гц не всегда означает рост активности альфа-ритма

Перед экспериментом проверьте контакт электродов, сохраняйте одинаковую позу и сравнивайте несколько повторений условия. На некоторых расположениях электродов альфа-ритм легче увидеть в спокойном состоянии с закрытыми глазами
