# Курс «Нейронауки и нейроинтерфейсы» — осень 2026

Добро пожаловать в репозиторий с проектными материалами курса Центрального университета «Нейронауки и нейроинтерфейсы»

## О проекте

Курс знакомит студентов с регистрацией и обработкой нейрофизиологических сигналов и постепенно подводит к созданию работающего интерфейса для управления физическим устройством

В проекте используется нейроинтерфейс Neiry HeadBand, Python и микроконтроллер ESP32. Финальная цель — собрать нейроинтерфейс для управления машинкой с помощью нейрофизиологических сигналов

## Структура репозитория

- [`CapsuleAPI`](./CapsuleAPI) — актуальная версия Capsule v2.0.98 для просмотра сигналов и метрик:
  - [`MacRelease`](./CapsuleAPI/MacRelease) — версия для macOS
  - [`WinRelease`](./CapsuleAPI/WinRelease) — версия для Windows
- [`CapsuleSDK`](./CapsuleSDK) — Python SDK, нативные библиотеки и примеры данных для работы с Neiry HeadBand
- [`lesson_1`](./lesson_1) — первое занятие: подключение устройства, получение ЭЭГ, импеданса, MEMS и PPG, визуализация ЭЭГ и первый интерфейс с биологической обратной связью

Следующие занятия будут добавляться по мере обновления курса:

- `lesson_2` — фильтрация ЭЭГ, спектральный анализ, альфа- и бета-ритмы
- `lesson_3` — ESP32, моторы и передача управляющих команд
- `lesson_4` — интеграция нейроинтерфейса с машинкой и финальный проект

## Начало работы

1. Установите Python 3.11 или новее.
2. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/GribanovDS/BSc-Neuroscience-and-Neurointerfaces-autumn-2026.git
   ```

3. Перейдите в корень репозитория:

   ```bash
   cd BSc-Neuroscience-and-Neurointerfaces-autumn-2026
   ```

4. Установите зависимости для всего курса одной командой:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Перейдите в папку нужного занятия
6. Подключите Neiry HeadBand и следуйте инструкции занятия

## Поддерживаемые платформы

- macOS — используется `CapsuleSDK/libCapsuleClient.dylib`
- Windows — используется `CapsuleSDK/CapsuleClient.dll`
